## 🚀 The Vision
Este não é apenas um portefólio; é uma **estação de trabalho digital**. Inspirado na precisão e estética das ferramentas da **JetBrains**, este projeto foi desenhado para demonstrar a atenção ao detalhe, a paixão por arquitetura limpa e a experiência nativa que aplico em cada linha de código.

## ✨ Key Features

### 📱 Reactive Mobile Emulator
Uma simulação de alta fidelidade de um dispositivo móvel integrada diretamente no Hero. 
- **Live Clock:** Sincronizado com o sistema.
- **Tabbed Navigation:** Experiência de app real (Home, Work, Me).
- **Responsive Layout:** Comportamento fluido em todos os viewports.

### 📜 Technical Changelog (Timeline)
Uma linha do tempo profissional desenhada como um log de versões/commits.
- **Left-Aligned Axis:** Estilo documentação técnica.
- **3D Parallax:** Cartões que reagem ao scroll com profundidade real.
- **Technical Metadata:** Inclusão de branches, hashes e timestamps fictícios para imersão total.

### 🎨 JetBrains Aesthetics
- **Branded Icons:** Logótipos oficiais coloridos (Kotlin, Android, Java, etc.).
- **IDE Typography:** Uso de fontes mono para realçar metadados e lógica.
- **Glassmorphism:** Interfaces translúcidas e sofisticadas com backdrop blurs profundos.

## 🛠️ Tech Stack
- **Frontend:** React 19 + Vite (Next-gen bundling)
- **Styling:** Tailwind CSS (Utility-first precision)
- **Animations:** Framer Motion (Hardware-accelerated motion)
- **Icons:** Lucide React + Custom SVG Brand Assets
- **Design System:** Custom JetBrains palette (`#7F52FF`, `#19191C`)

## ⚡ Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/imperador1k/Port-test.git
```

### 2. Install dependencies
```bash
npm install
```

### 3. Launch the IDE
```bash
npm run dev
```

## 🧬 Architecture Patterns
O projeto segue princípios de **Componentização Atómica** e **Declarative UI**, garantindo que cada secção seja independente e altamente performante. A lógica de animação é desacoplada para garantir 60fps constantes mesmo em dispositivos móveis.
